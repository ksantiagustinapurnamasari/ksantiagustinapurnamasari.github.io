# Biodata Ksanti Agustina Purnamasari

Website pribadi mahasiswa Program Studi **Bisnis Manajemen Buddha** di **STIAB Jinarakkhita Lampung**, dengan tampilan responsif untuk ponsel dan desktop.

## Halaman

- `index.html`: Beranda.
- `profil.html`: Identitas dan profil mahasiswa.
- `tentang.html`: Perkenalan diri.
- `pendidikan.html`: Informasi pendidikan.
- `galeri.html`: Galeri foto dan karya web dengan kategori serta deskripsi.
- `kontak.html`: Tautan profil GitHub.

Setiap halaman memiliki menu yang menghubungkan keenam halaman dan menandai halaman aktif. Link lama seperti `/#profil` dan `/#galeri` otomatis membuka halaman yang sesuai.

## GitHub Pages

Alamat tujuan: https://ksantiagustinapurnamasari.github.io/

1. Masuk ke akun GitHub `ksantiagustinapurnamasari`.
2. Buat repositori **Public** dengan nama persis `ksantiagustinapurnamasari.github.io`.
3. Unggah keenam file HTML di atas, `styles.css`, `theme.css`, `script.js`, `.nojekyll`, folder `.github`, dan folder `assets` ke direktori utama repositori. Jangan mengunggah file ZIP atau folder pembungkusnya.
4. Repositori ini memakai workflow publikasi di `.github/workflows/deploy.yml`. Buka **Settings → Pages**, lalu pilih **GitHub Actions** sebagai sumber penerbitan.
5. Tunggu penerbitan selesai. Statusnya dapat dilihat di **Actions** atau **Settings → Pages**.

Setiap perubahan yang diunggah ke cabang `main` akan diterbitkan otomatis. Tidak memerlukan Node.js atau instalasi paket. Untuk melihat secara lokal, buka `index.html` di browser.

## Mengubah isi

- Perkenalan di beranda: `index.html`.
- Identitas dan profil: `profil.html`.
- Deskripsi diri: `tentang.html`.
- Informasi pendidikan: `pendidikan.html`.
- Galeri dan deskripsi karya: `galeri.html`.
- Tautan kontak: `kontak.html`.
- Warna dan penyesuaian tampilan: `theme.css`.
- Menu navigasi ponsel: `script.js`.
- Foto profil berada di `assets/foto-profil.jpeg` dan tampil di Beranda, Profil, serta di sebelah nama pada menu.

Font DM Sans disertakan secara lokal dengan lisensi SIL Open Font License di `assets/OFL.txt`.
