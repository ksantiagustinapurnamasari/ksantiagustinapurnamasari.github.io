# Biodata Ksanti Agustina Purnamasari

Website pribadi mahasiswa Program Studi **Bisnis Manajemen Buddha** di **STIAB Jinarakkhita Lampung**, dengan tampilan responsif untuk ponsel dan desktop.

## GitHub Pages

Alamat tujuan: https://ksantiagustinapurnamasari.github.io/

1. Masuk ke akun GitHub `ksantiagustinapurnamasari`.
2. Buat repositori **Public** dengan nama persis `ksantiagustinapurnamasari.github.io`.
3. Unggah isi paket: `index.html`, `styles.css`, `theme.css`, `script.js`, `.nojekyll`, dan folder `assets` ke direktori utama repositori. Jangan mengunggah file ZIP atau folder pembungkusnya.
4. Buka **Settings → Pages**. Pada **Build and deployment**, pilih **Deploy from a branch**, lalu **main** dan **/ (root)**, kemudian **Save**.
5. Tunggu penerbitan selesai. Statusnya dapat dilihat di **Actions** atau **Settings → Pages**.

Tidak memerlukan Node.js, instalasi paket, atau proses build. Untuk melihat secara lokal, buka `index.html` di browser.

## Mengubah isi

- Nama, informasi pendidikan, dan tautan GitHub: `index.html`.
- Warna dan penyesuaian tampilan: `theme.css`.
- Menu navigasi ponsel: `script.js`.
- Area profil menggunakan inisial KAP. Untuk memakai foto, ganti elemen `.monogram` dengan `<img src="assets/foto-saya.jpg" alt="Foto Ksanti Agustina Purnamasari">`, lalu simpan foto di folder `assets`.

Font DM Sans disertakan secara lokal dengan lisensi SIL Open Font License di `assets/OFL.txt`.
